# EXECUTION PROTOCOL — FOLLOW EXACTLY IN ORDER

**CRITICAL CONSTRAINT: Each write_file/patch call must be under 200 words. Write one section at a time. Do NOT generate the full report at once.**

## PHASE 1 — Analysis (max 25 tool calls total)

Execute in order:

1. `read_file .shannon/deliverables/recon_deliverable.md`
2. `read_file .shannon/deliverables/pre_recon_deliverable.md`
3. Run these greps:
   - `grep -rn "exec(\|execSync(\|spawn(\|system(" src/ 2>/dev/null | grep -v node_modules | head -20`
   - `grep -rn "readFile(\|writeFile(\|createReadStream\|path\.join\|path\.resolve" src/app/api 2>/dev/null | head -20`
   - `grep -rn "\.rpc(\|\.query(\|raw.*sql\|rawQuery\|template.*literal" src/ 2>/dev/null | grep -v node_modules | head -20`
   - `grep -rn "render(\|compile(\|eval(\|Function(" src/app/api 2>/dev/null | head -20`
4. Read 2-3 source files flagged by greps as potentially dangerous

**After 25 tool calls, STOP and go to Phase 2 immediately. No exceptions.**
